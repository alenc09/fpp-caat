# Data Dictionary

This directory contains the analysis-ready tables used to reproduce all figures, statistical models, and supplementary tables in the manuscript. These tables are the outputs of a pre-processing pipeline that integrates multiple public datasets (see *Origins* below).

---

## Files included in this repository

### Core analysis tables

| File | Unit | Description |
|------|------|-------------|
| `tabela_buffer_nova.xlsx` | Landscape buffer (5 km radius) | Main buffer-scale table. One row per FPP settlement buffer. Contains forest cover (%) for 2010, 2011, 2017, 2018, 2022, 2023; rural population (FPP) for 2010 and 2022; and socioeconomic indicators per buffer. Generated by `DO_01_tab_geral.R`. |
| `tabela_mun_nova.xlsx` | Municipality | Main municipality-scale table. One row per municipality in the Caatinga. Contains mean forest cover and FPP values aggregated from buffer scale, plus municipality-level socioeconomic variables. Generated by `DO_01_tab_geral.R`. |
| `tabela_mun_50.xlsx` | Municipality | Municipality-scale table for threshold sensitivity analysis at 50% forest cover. |
| `tabela_mun_70.xlsx` | Municipality | Municipality-scale table for threshold sensitivity analysis at 70% forest cover. |
| `tab_buffer_analysis.csv` | Landscape buffer | Analysis-ready buffer table with derived variables: absolute and relative forest cover change, FPP change, and 4-category classification (GG/GP/PG/PP). Generated by `DO_02_tab_analysis.R` from `tabela_buffer_nova.xlsx`. |
| `tab_mun_analysis.csv` | Municipality | Analysis-ready municipality table with derived variables and change category. Generated by `DO_02_tab_analysis.R` from `tabela_mun_nova.xlsx`. Used by spatial models and maps. |
| `tab_mun_analysis_50.csv` | Municipality | As above, at 50% forest cover threshold. |
| `tab_mun_analysis_70.csv` | Municipality | As above, at 70% forest cover threshold. |

## Change category definitions

The `cat_change` variable classifies each landscape/municipality by the direction of change in forest cover and FPP between 2010 and 2022:

| Code | Forest cover | FPP |
|------|-------------|-----|
| `GG` | Gain | Gain |
| `GP` | Gain | Loss |
| `PG` | Loss | Gain |
| `PP` | Loss | Loss |

`stable` = no meaningful change in forest cover.

## Origins of the data in these tables

The tables integrate the following public datasets, processed in `DO_01_tab_geral.R`, `PP_01_buffer_lc.R`, and `PP_02_buffer_pop.R`:

| Variable group | Source | Access |
|----------------|--------|--------|
| Forest cover (2010–2023) | MapBiomas Collection 9 — Annual Land Use and Land Cover Maps | [mapbiomas.org](https://mapbiomas.org) |
| Rural population (FPP) 2010 | IBGE Census 2010 — census tract microdata | [sidra.ibge.gov.br](https://sidra.ibge.gov.br) / `censobr` R package |
| Rural population (FPP) 2022 | IBGE Census 2022 — census tract microdata | [sidra.ibge.gov.br](https://sidra.ibge.gov.br) / `censobr` R package |
| Municipality population | IBGE — Municipal population estimates | [ibge.gov.br](https://www.ibge.gov.br) |
| Poverty (CadÚnico) | Ministry of Citizenship — Single Registry (CadÚnico) | Available on request from the Ministry |
| Health index (IFDM) | Firjan — Municipal Development Index | [firjan.com.br](https://www.firjan.com.br) |
| Under-5 mortality | SIM/DATASUS — Brazilian Mortality Information System | [datasus.saude.gov.br](https://datasus.saude.gov.br) |
| Sanitation & lighting | IBGE Census 2010 and 2022 — household characteristics | [sidra.ibge.gov.br](https://sidra.ibge.gov.br) |
| Water cisterns | MDS — Cistern programme data | Available on request from MDS |
| Irrigation demand | ANA — National Water Agency (Hidroweb) | [snirh.gov.br](https://www.snirh.gov.br) |
| Livestock density | IBGE — Agricultural Census (PPM) | [sidra.ibge.gov.br](https://sidra.ibge.gov.br) |
| Agricultural GDP | IBGE — Municipal GDP | [ibge.gov.br](https://www.ibge.gov.br) |
| Family farming share | MDA / IBGE — Family farming registry | [sidra.ibge.gov.br](https://sidra.ibge.gov.br) |
| FPP settlement locations | Bastin et al. 2017 — Supplementary Database S1 | [doi.org/10.1126/science.aam6527](https://doi.org/10.1126/science.aam6527) |
| Municipality and state boundaries | IBGE via `geobr` R package | Downloaded automatically by scripts |
| Caatinga biome boundary | IBGE via `geobr` R package | Downloaded automatically by scripts |

> Data used in this study are publicly available. Datasets that require registration or a data request (CadÚnico, cisterns) can be obtained from the relevant ministries. The authors can provide the processed tables upon request.
